# Tema 4: Aprofundamento de Funções

## 1. Condições de Existência e Domínio Real
- **Fração**: denominador diferente de zero (D(x) ≠ 0).
- **Raiz de índice par no numerador**: radicando não-negativo (g(x) ≥ 0).
- **Raiz de índice par no denominador**: radicando estritamente positivo (g(x) > 0).

## 2. Tipos de Função
- **Injetora**: elementos distintos no domínio geram imagens distintas (x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)).
- **Sobrejetora**: o conjunto imagem coincide com todo o contradomínio ( ext{Im}(f) = CD).
- **Bijetora**: simultaneamente Injetora e Sobrejetora.
- **Inversibilidade**: uma função admite inversa f⁻¹(x) **se e somente se** for bijetora.

## 3. Imagem em Domínio Restrito
- Ao analisar a imagem de f(x) = ax² + bx + c em um intervalo [x₁, x₂], verifique primeiro se o vértice x_v está **dentro** do intervalo!
- Se x_v ∉ [x₁, x₂], os extremos da imagem ocorrerão nas bordas f(x₁) e f(x₂).

## 4. Funções Periódicas
- Uma função é periódica de período P > 0 se f(x + P) = f(x) para todo x.
- Para valores grandes de argumento, use múltiplos inteiros do período:
 
> **f(x + k · P) = f(x)**
