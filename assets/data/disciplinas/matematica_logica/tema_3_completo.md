# Gráficos e Interpretações Gráficas (Conteúdo Completo)

> 💡 **DICA DE OURO**: Ao analisar gráficos em questões de física ou economia, sempre observe as unidades nos eixos e qual grandeza corresponde a x (variável independente) e a y (variável dependente).

---

## 1. O Plano Cartesiano Ortogonal
O plano cartesiano divide o espaço bidimensional em quatro quadrantes determinados pelo cruzamento perpendicular do eixo das abscissas (x) e do eixo das ordenadas (y):
- **1º Quadrante**: x > 0 e y > 0
- **2º Quadrante**: x < 0 e y > 0
- **3º Quadrante**: x < 0 e y < 0
- **4º Quadrante**: x > 0 e y < 0

### Simetrias no Plano
- **Simetria em relação ao eixo x**: (x, y) → (x, -y)
- **Simetria em relação ao eixo y**: (x, y) → (-x, y)
- **Simetria em relação à origem (0, 0)**: (x, y) → (-x, -y)

---

## 2. Retas e Taxa de Variação Média
A equação de uma reta é dada por y = mx + b, onde:
- m é o **coeficiente angular** (taxa de variação ou inclinação):
 
> **m = (Δ y) / (Δ x) = (y₂ - y₁) / (x₂ - x₁)**

- b é o **coeficiente linear** (ponto onde a reta corta o eixo das ordenadas y, quando x = 0).

---

## 3. Parábolas e Funções Quadráticas (y = ax² + bx + c)
O gráfico de uma função polinomial do 2º grau é uma parábola:
- **Concavidade**: Se a > 0, a concavidade é voltada para cima (o vértice é ponto de **mínimo** global). Se a < 0, a concavidade é voltada para baixo (o vértice é ponto de **máximo** global).
- **Coordenadas do Vértice**:
 
> **x_v = -(b) / (2a), y_v = -(Δ) / (4a) = f(x_v)**

 Onde Δ = b² - 4ac.

> ⚠️ **PEGADINHA DE PROVA**: Ordem das grandezas pedidas no par ordenado!
> Em trajetórias de projéteis (ex: y = -5x² + 100x), o vértice é (x_v, y_v) = (10, 500). Mas se o enunciado solicitar explicitamente o par **(altura máxima; alcance horizontal)**, a resposta correta é **(500; 20)**, invertendo a ordem convencional das coordenadas!
