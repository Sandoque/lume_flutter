# Fórmulas & Regras de Ouro: Funções

### 🎯 Restrições de Domínio Real
- Fração (1) / (D(x)): D(x) ≠ 0
- Raiz no numerador √(g(x)): g(x) ≥ 0
- Raiz no denominador (1) / (√(g(x))): g(x) > 0 (estrito)

### 🎯 Bijeção e Inversa
- Injetora: x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)
- Sobrejetora: Im(f) = CD
- Bijeção: Injetora E Sobrejetora ⇔ Admite Inversa f⁻¹

### 🎯 Periodicidade
- f(x + k · P) = f(x) para qualquer k ∈ ℤ
