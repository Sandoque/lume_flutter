# Fórmulas & Regras de Ouro: Cálculo de Predicados

### 🎯 Negação de Quantificadores
- ¬ ∀ x P(x) ≡ ∃ x ¬ P(x)
- ¬ ∃ x P(x) ≡ ∀ x ¬ P(x)

### 🎯 Ordem de Quantificadores
- ∀ x ∃ y P(x, y) \not≡ ∃ y ∀ x P(x, y)

### 🎯 Sintaxe Prolog
- Átomos/Constantes: minúsculas (`pai(carlos, mario).`)
- Variáveis: maiúsculas (`X`, `Y`)
