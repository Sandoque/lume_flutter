# Fórmulas & Regras de Ouro: Gráficos e Interpretações

### 🎯 Parábola (y = ax² + bx + c)
- Vértice no eixo x: x_v = -(b) / (2a)
- Altura / Extremo no eixo y: y_v = -(Δ) / (4a)
- Discriminante: Δ = b² - 4ac
- Raízes / Alcance: ax² + bx + c = 0 ⇒ x = (-b ± √(Δ)) / (2a)

### 🎯 Retas e Inclinação
- Coeficiente angular: m = (Δ y) / (Δ x) = (y₂ - y₁) / (x₂ - x₁)
- Equação reduzida: y = mx + b
