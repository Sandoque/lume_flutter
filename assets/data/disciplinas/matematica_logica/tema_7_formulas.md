# Fórmulas & Regras de Ouro: Métodos de Demonstração

### 🎯 Métodos para H → T
- **Direta**: assume H ≡ V, deduz T ≡ V
- **Contraposição**: prova ¬ T → ¬ H
- **Absurdo**: assume H ∧ ¬ T, deduz contradição C ∧ ¬ C
- **Trivial**: T é sempre V (H → V ≡ V)
- **Vacuidade**: H é sempre F (F → T ≡ V)
- **Contraexemplo**: 1 caso falso derruba afirmativa universal ∀ x

### 🎯 Passos do PIF (Indução)
1. Base: provar P(1)
2. Hipótese: assumir P(k)
3. Passo: demonstrar P(k + 1)
